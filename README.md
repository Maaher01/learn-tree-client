# LearnTree – Online Classroom Platform

LearnTree is a full-stack, role-based online classroom platform where students and teachers can collaborate through subject-specific classes, announcements, and discussions.

---

## Features

### User Roles

* Register as **Student** or **Teacher**
* Role-based access and functionality

### Authentication & Authorization

* Secure user authentication system
* Role-based access control for features and routes

### Class Management

* Join or leave classes based on subject and grade
* Organized class structure for better learning experience

### Announcements

* Teachers can create, edit, and delete announcements
* Class-specific announcement feeds

### Discussion System

* Threaded comments on announcements
* Users can edit or delete their own comments
* Enables interactive communication between students and teachers

### Participants

* View class participant lists
* Display user information including email visibility

## Setup Instructions (Optional)

### Backend

1. Clone the server repository
2. Configure environment variables (database connection, secrets)
3. Setup database
4. Start the server

### Frontend

1. Clone the client repository
2. Install dependencies:

   ```bash
   npm install
   ```
3. Start the application:

   ```bash
   npm start
   ```
